# sh-web

Sudut Haramain — Media Digital & Informasi Praktis Makkah–Madinah.

M5A.1 is an intentionally minimal Nuxt 3 domain-validation baseline for `sudutharamain.id`. It has no backend, CMS, or API integration.

## Development

```bash
npm ci
npm run dev
```

## Validation

```bash
npm run build
```

Target domains:

- `sudutharamain.id` → this app
- `tour.sudutharamain.id` → existing `sht-web`
